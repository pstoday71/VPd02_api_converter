# VPd02_api_converter

CLI-приложение для просмотра курсов валют и конвертации через бесплатный [ExchangeRate API](https://open.er-api.com/v6/latest).

## Возможности

- Получение актуальных курсов относительно заданной базовой валюты (например `USD`)
- Вывод курсов популярных валют: RUB, EUR, GBP, USD, CNY, JPY, KZT, UAH, BYN, KGS
- Конвертация суммы из одной валюты в другую
- Кэширование ответа API в `currency_rate.json` (обновление, если кэш старше 24 часов)
- Понятные сообщения об ошибках (сетевые, ошибки API, некорректные коды валют и суммы)

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Зависимость: `requests>=2.31`.

## Использование

```powershell
python currency.py
```

Запустится CLI, который:

1. Спросит базовую валюту (по умолчанию `USD`)
2. Покажет курсы относительно неё
3. Позволит сконвертировать сумму

Пример:

```
Базовая валюта (например USD): USD

Курсы относительно USD:
  RUB: 92.1040
  EUR: 0.9240
  ...

Из какой валюты: RUB
В какую валюту: EUR
Сумма: 10000
10000.0000 RUB = 100.3365 EUR
```

## Структура

```
currency.py      точка входа (запускает CLI)
cli.py           CLI-интерфейс, кэш, конвертация
api_client.py    запрос курсов к API и обработка ошибок
storage.py       сохранение/чтение кэша и проверка свежести
currency_rate.json  кэш последнего ответа API (создаётся автоматически)
requirements.txt    зависимости проекта
```

> `currency_rate.json` не отслеживается git — кэш создаётся локально при первом запуске.
